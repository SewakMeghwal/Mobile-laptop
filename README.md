# 📱 Mobile Laptop Shop

A modern, full-featured Django web application for buying and exploring smartphones, laptops, and tech accessories. Built with Django, Bootstrap 5, Cloudinary image management, WhiteNoise production static file serving, and interactive shopping cart functionality.

---

## ✨ Features

- 🛒 **Interactive Shopping Cart**: Add, manage quantity, remove, and checkout items session-wise across all categories.
- 🔍 **Unified Product Search**: Search seamlessly across Mobiles, Laptops, and Accessories simultaneously with keyword matching.
- 📱 **Mobile & Laptop Catalog**: Browse detailed specification pages (`Read More`), category filters, and product inventory.
- 👤 **User Authentication & Profile**: User sign-up, login, logout, profile picture upload via Cloudinary, and personal account dashboard.
- 🎨 **Modern Responsive UI**: Custom design system featuring glassmorphic cards, FontAwesome 6 vector icons, micro-animations, and mobile-first Bootstrap 5 grids.
- ⚡ **Production Ready**: Integrated WhiteNoise static asset compression & caching for deployment on platforms like Render.
- 🛡️ **Image Fallback System**: Automated SVG placeholders prevent broken layout glitches if remote image links fail.

---

## 🛠️ Technology Stack

- **Backend Framework**: Python 3.10+ / Django 4.1+ & 5.x
- **Frontend**: HTML5, Vanilla CSS3 (Custom Design Tokens), Bootstrap 5.3, FontAwesome 6
- **Forms**: Django Crispy Forms & Crispy Bootstrap 5
- **Media Storage**: Cloudinary API
- **Static Assets**: WhiteNoise (`CompressedManifestStaticFilesStorage`)
- **Database**: SQLite (Development / Standalone)
- **WSGI / Production Server**: Gunicorn

## 🚀 Quick Start (Local Development)

### 1. Clone the Repository
```bash
git clone https://github.com/Sewak2001/Mobile-laptop.git
cd Mobile-laptop
```

### 2. Set Up Virtual Environment & Install Dependencies
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Run Database Migrations
```bash
python manage.py migrate
```

### 4. Start Development Server
```bash
python manage.py runserver
```
Navigate to `http://127.0.0.1:8000/` in your browser.

## 🌐 Production Deployment (Render)

When deploying to [Render](https://render.com):

1. **Build Command**:
   ```bash
   pip install -r requirements.txt && python manage.py collectstatic --noinput
   ```
2. **Start Command**:
   ```bash
   gunicorn web_pro.wsgi:application
   ```
3. **Environment Variables**:
   - `DEBUG`: `False`
   - `PYTHON_VERSION`: `3.10.11` (or matching Python version)
